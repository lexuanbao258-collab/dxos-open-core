Ví dụ tích hợp

Các ví dụ chỉ dùng Backend demo local. Đây là mã tham khảo, không phải bằng chứng đã chạy valid-JWT end-to-end. Không đưa token thật vào GitHub hoặc website.

Điều kiện trước khi thửBackend local trên 127.0.0.1:8080, Keycloak issuer thật, database disposable, tài khoản đã được cấp tenant membership và quyền đọc. Database Swagger trước đó có ACTORS=0: nếu chưa provision actor, các ví dụ sẽ không thành công.
01 / PowerShell

PowerShell — đọc danh sách

PowerShell 5.1+ · GET
$secure = Read-Host 'Access token (ẩn)' -AsSecureString
$cred = [pscredential]::new('token', $secure)
$jwt = $cred.GetNetworkCredential().Password
try {
  $options = @{
    Uri = 'http://127.0.0.1:8080/api/v1/mvp/requests?limit=10'
    Headers = @{Authorization = "Bearer $jwt"}
    Method = 'GET'
  }
  $page = Invoke-RestMethod @options
  $page.items | Select-Object id, title, state, version
} finally {
  $jwt = $null
  $cred = $null
  $secure = $null
}

Không in JWT trong console/screenshot. Mật khẩu hoặc token vẫn có thể tồn tại trong process memory; đây là demo local, không phải kho lưu trữ bí mật.

02 / JavaScript

Node.js — Fetch API

Node.js 20+ · GET
const token = process.env.DXOS_DEMO_ACCESS_TOKEN;
if (!token) throw new Error('Missing local demo token');
const response = await fetch(
  'http://127.0.0.1:8080/api/v1/mvp/requests?limit=10',
  { headers: { Authorization: 'Bearer ' + token } }
);
if (!response.ok) {
  throw new Error('HTTP ' + response.status);
}
const page = await response.json();
console.log(page.items.map(({ id, state }) => ({ id, state })));

Chỉ chạy trong Node.js local, không nhúng bearer token vào mã frontend công khai. Không log nội dung request nếu có dữ liệu nội bộ.

03 / Java 21

Java HttpClient — kiểm tra HTTP

Java 21 · GET
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

class DxosExample {
  public static void main(String[] args) throws Exception {
    String token = System.getenv("DXOS_DEMO_ACCESS_TOKEN");
    if (token == null || token.isBlank())
      throw new IllegalStateException("Missing local token");
    var req = HttpRequest.newBuilder(URI.create(
        "http://127.0.0.1:8080/api/v1/mvp/requests?limit=10"))
        .header("Authorization", "Bearer " + token)
        .GET().build();
    try (var client = HttpClient.newHttpClient()) {
      var response = client.send(req, HttpResponse.BodyHandlers.discarding());
      System.out.println("HTTP " + response.statusCode());
      if (response.statusCode() != 200)
        throw new IllegalStateException("Read failed");
    }
  }
}

Không in response body để tránh đưa dữ liệu nội bộ vào log. Parse JSON sau khi xác minh schema thực tế.
