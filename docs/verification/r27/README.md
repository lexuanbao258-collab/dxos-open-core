## Convention (proposal; not retroactive)

- **IDs:** `R27-INV/DEC/REG/EVD/LIC/EXC/REV/RPT/VER-NNN` identify *documents*, not source or rights decision rows. Keep existing source IDs and paths unchanged. This index uses `R27-REG-DOC-001` to avoid collision with the existing rights register.
- **Document status:** `Planned | Draft | In Review | Approved | Superseded`. Approval of a document does not imply approval of file/source rights.
- **Evidence verification:** `PASS | PARTIAL | FAIL | NOT_VERIFIED`. Specify the exact claim and SHA verified.
- **Rights disposition:** `PENDING | CLEARED | REMEDIATION_REQUIRED | EXCLUDED | NOT_APPLICABLE`. A `CLEARED` decision requires scoped evidence, applicable license/NOTICE review and a separate reviewer, never just CI or SPDX metadata.
- **New documents:** follow `r27-<type>-<subject>.md` where practical, include SPDX/REUSE metadata, stable ID, version, scope, exact baseline, owner, reviewer, evidence URLs, open items, disposition and review history. **Do not rename existing evidence files** merely to match this convention.
- **Evidence trace:** record source path, Git blob SHA, commit/hunk when needed, direct contributor statement, identified upstream source/license/notice, reviewer, decision and next action. Unknown inputs or AI-output ancestry must stay `UNKNOWN/PENDING`; do not invent negative claims or source URLs.
- **Baselines:** `5daa145d` is the historical Identity audit SHA; `187dbd2` is the R24 source-only candidate. A change to source distribution inputs requires delta reconciliation and, where applicable, fresh artifact verification. A PR documentation HEAD is **not** the frozen release source SHA.
- **Release boundary:** [Issue #138](https://github.com/tricore-opentrix/opentrix/issues/138) remains OPEN and [R24 #139](https://github.com/tricore-opentrix/opentrix/pull/139) remains Draft / release BLOCKED until reviewed rights and obligations support a distinct authorized R24 acceptance.

## Maintenance rules

1. Update this index **after** a document, declaration or independent review is actually published; use exact PR/commit/comment links. Do not claim a proposed record exists.
2. Keep the canonical source-rights remediation rows in `r27-rights-remediation-register-187dbd2.csv`; do not create a second competing disposition ledger here.
3. Never convert evidence-owner/reviewer assignments into inferred copyright ownership or licensing grants.
4. For mixed-authorship files, record contributor-specific portions and reviewer decisions separately.
5. If a linked Draft PR HEAD advances, update the pinned link/status in a small reviewed documentation change; retain historical baselines for audit.
6. A successful CI, two-run reproducible archive or technically accepted document is **not** permission to distribute.
