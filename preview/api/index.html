Danh sách API

Trình hiển thị Scalar cần tải thư viện từ CDN. Nếu không thấy giao diện tương tác tài liệu, bạn vẫn có thể xem 9 endpoint dưới đây và tệp OpenAPI JSON bản thảo.

  • GET /api/v1/mvp/requests — Danh sách
  • POST /api/v1/mvp/requests — Tạo yêu cầu
  • GET /api/v1/mvp/requests/{id} — Chi tiết
  • GET /api/v1/mvp/requests/{id}/history — Lịch sử
  • POST /api/v1/mvp/requests/{id}/triage — Tiếp nhận
  • POST /api/v1/mvp/requests/{id}/assign — Phân công
  • POST /api/v1/mvp/requests/{id}/start — Bắt đầu
  • POST /api/v1/mvp/requests/{id}/resolve — Xử lý xong
  • POST /api/v1/mvp/requests/{id}/confirm — Xác nhận
