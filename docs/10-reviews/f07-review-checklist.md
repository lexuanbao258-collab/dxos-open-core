# F07 — ADR Governance and Index Review Checklist

> **State:** DRAFT / NOT REVIEWED  
> **Target:** `docs/08-decisions/README.md`  
> **Decision source:** 15 user-approved F07 questionnaire choices

## Policy and Content

- [ ] Lightweight governance and index model follows the F07 decision set (Q01–Q15).
- [ ] ADR trigger criteria cover architecture, security, Core contracts, data and deployment.
- [ ] Required template contains Context, Alternatives, Decision, Rationale, Consequences and Verification.
- [ ] Alternative evaluation uses relevant maintainability/security/reuse/testability/deployment/cost criteria.
- [ ] ADR lifecycle is separated from document lifecycle.
- [ ] Accepted is not equated with implementation or testing.
- [ ] Independent reviewer and designated decision authority requirements are explicit.
- [ ] Open Issues and ADRs have separate purposes and traceable links.
- [ ] Supersession preserves the historical ADR and links the replacement.
- [ ] English Markdown, headings, Mermaid syntax and editorial conventions are checked.

## Baseline and Inventory

- [ ] Code repository remote, branch, complete SHA and reviewed date captured.
- [ ] Documentation repository remote, branch, complete SHA and reviewed date captured.
- [ ] All tracked ADR filenames are enumerated from both repositories.
- [ ] Existing identifiers and original filename padding are preserved.
- [ ] Duplicate/missing ID references are investigated before new IDs are allocated.
- [ ] ADR titles and links resolve to tracked, reviewed files.
- [ ] Each claimed Accepted/Rejected/Superseded status has actual decision evidence.
- [ ] Supersedes references and status synchronization are checked against source ADRs.
- [ ] Document Register reflects file-specific status without copying ADR decision lifecycle.

## Approval

- [ ] Independent reviewer is identified and not the primary author.
- [ ] Decision authority and approval basis are explicitly documented.
- [ ] Required findings have severity, owner, resolution and review links.
- [ ] The F07 review is pinned to a verified docs/code baseline.
- [ ] Reviewer decision and Gate Approver sign-off are recorded before any PASS claim.
