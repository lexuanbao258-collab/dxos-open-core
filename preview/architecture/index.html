02 / Security gates

Kiểm tra một yêu cầu

  1. HTTP Authentication

    Security filter xác thực bearer access token qua JWT issuer, chữ ký, audience, expiration và kiểu token.

  2. Tenant membership & visibility

    Với tài nguyên có ID, Backend xác định người dùng có được biết tài nguyên tồn tại không; tài nguyên ẩn/khác tenant không được tiết lộ.

  3. Operation authority & ACL

    Phân biệt quyền Workflow (đọc, chuyển trạng thái...) và quy tắc nghiệp vụ Employee, Coordinator, Worker.

  4. Workflow state, expectedVersion & write-time checks

    Đọc lại dữ liệu khi xử lý thao tác ghi, kiểm tra phiên bản để ngăn áp dụng lệnh từ trạng thái cũ.
